# 검증 기록

## Paseo 0.12.0 호환성 갱신 · 2026-10-22

세 플러그인의 개발 SDK·클라이언트·프로토콜을 0.12.0으로 고정하고, 기존 기능을 유지한 채 manifest의 버전 상한을 제거했습니다. 세 프로젝트의 타입 검사와 0.12.0 서버 컴파일러의 클라이언트·서버 번들을 확인했습니다. 계정 플러그인 단위 테스트 99개, 시스템 관리 단위 테스트 18개와 관리자 도우미 테스트 3개, Home Finder의 임시 파일·URL·미디어 번들 검사를 통과했습니다. 계정 테스트의 오래된 '업데이트' 오류 문구 기대값을 현재 '예약 전송 안전 기능' 안내에 맞췄습니다.

Home Finder 휴지통 검증은 GIO가 내부 마운트로 취급하는 `/tmp`를 피하고 홈 파일시스템의 임시 폴더에서 실행했습니다. 실사용 파일·컨테이너 정리, 모델 요청과 실계정 리셋권 소비는 수행하지 않았습니다. Ubuntu의 현재 daemon 0.11.4에서 메인 daemon 재시작 없이 세 플러그인을 reload해 모두 running을 확인했습니다. 파일 목록·시스템 상태·예약 조회 RPC가 정상 응답했고 91개 세션의 provider/session ID와 계정 선택·자동 전환·자동 재개 설정을 보존했습니다. 현재 호스트는 예약 안전 확장이 미적용되어 예약 전송 지원은 false입니다. 0.12.0 daemon과 실제 모바일 기기는 직접 검증하지 않았습니다. 예약 전송에는 기존과 같이 호스트 안전 확장이 필요합니다.
